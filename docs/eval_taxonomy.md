# AI 评测场景 Taxonomy（V1）

> 现有用例先归位，空缺节点后续补充。

| 维度节点 | 中文名 | 子场景 | 典型失败标签 | 现有用例来源 |
|---|---|---|---|---|
| interaction | 智能交互 | 多轮对话、歧义意图、答非所问 | 答非所问、幻觉 | AG-NEG-005 |
| planning | 复杂任务执行 | 任务拆解、规划、逻辑一致性 | 逻辑混乱、过早终止、任务中断 | AG-NEG-001/004/006 |
| tool_scheduling | 工具调度 | Function Calling、工具选择、参数 | 错调用、工具选错、参数错误、漏执行 | AG-NEG-002/003 |
| link_scheduling | 链路调度(Harness) | 任务分发、多模型切换、并发适配、时效 | 路由错误、并发串线、响应延迟 | HAR-001/003 |
| memory | 记忆调取与留存 | 偏好留存、一致性、冲突、丢失、冗余、遗忘 | 记忆丢失、记忆冲突、冗余记忆、前后不一致 | MEM-001~005 |
| fault_tolerance | 异常容错 | 超时兜底、降级、故障注入、边界保密 | 兜底未生效、死循环、越权泄露、场景适配失效 | AG-NEG-004, HAR-002/004, MEM-005 |

## 问题分类与判定口径

- **漏执行**：用例期望调用的工具/步骤未出现。
- **错调用**：调用了禁用工具或错误工具。
- **参数错误**：工具被选中但关键入参缺失/非法。
- **死循环**：同一工具+相近入参连续重复 ≥3 次。
- **过早终止**：轨迹中断且期望动作未完成。
- **答非所问**：期望关键信息未在回答/轨迹中出现。
- **记忆冲突**：未采用最新事实，回退到旧偏好。
- **冗余记忆**：回答重复已确认信息超阈值。
