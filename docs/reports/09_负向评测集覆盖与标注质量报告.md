# 09 负向评测集覆盖与标注质量报告

> 数据源：`datasets/agent/agent-negative-cases.json`
> 判定口径：`core/evaluator.py::_eval_agent_negative`
> 统计脚本：`python tools/coverage_report.py datasets/agent/agent-negative-cases.json`

## 1. 总体指标

| 指标 | 现状 |
|---|---|
| 用例总数 | 12（6 条真实跑 + 6 条预设轨迹） |
| 四类失败模式覆盖 | 4/4（planning_error / infinite_loop / wrong_tool_call / early_termination） |
| taxonomy 维度覆盖 | 4/6（fault_tolerance 6 / tool_scheduling 5 / interaction 5 / planning 4） |
| 标注完整率 | 100%（taxonomy 与 fail_labels 均无空缺） |
| 标签体系 | 15 类、22 个标签实例 |

## 2. 失败模式 × 用例

| 失败模式 | 判定条件 | 对应用例 |
|---|---|---|
| planning_error | 工具序列与 expected_steps 不一致（澄清场景豁免） | AN2 / AN3 / AN6 / BN02 |
| infinite_loop | 同工具同参数重复 > 2 次，或非 reply 工具调用 > 3 次 | BN02 |
| wrong_tool_call | 调用不在 tools 白名单内的工具 | BN03B（hack_tool） |
| early_termination | 工具报错后最后一步不是 reply | BN05 |

## 3. 已修复的缺陷

| 缺陷 | 表现 | 处理 |
|---|---|---|
| 统计字段名不匹配 | 脚本读 failure_labels，数据集实际为 fail_labels，标签分布恒为空 | 兼容两种写法，新增未标注清单 |
| 口径漂移 | 数据集 BN01 期望序列为 3 项、单测为 2 项，导致该用例恒 FAIL | 数据集对齐单测 |
| 零覆盖死分支 | early_termination 有判定无样本 | 新增 BN05，按隔离命中设计期望序列 |

## 4. 代表性与已知缺口

- 工具维度：get_weather 11 / calculate_exchange 5，仅覆盖查询类与计算类，缺写操作类工具
- 澄清分支：需澄清 5 / 不需澄清 7，可验证 clarification 豁免边界
- 难度分布：hard 5 / medium 4 / easy 3，符合负向集以坏样本为主的定位
- 平均工具数 1.33，缺 3 步以上长程规划样本

taxonomy 缺 memory 与 link_scheduling：两者由 `datasets/memory`、`datasets/harness` 独立评测层覆盖，负向集只负责轨迹级失败归因，不重复建设。
